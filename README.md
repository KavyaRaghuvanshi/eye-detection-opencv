# 👁️ Real-Time Eye Detection using OpenCV

## 📌 Project Overview

This project implements a real-time eye detection system using OpenCV and Haar Cascade Classifiers. The application captures live video from a webcam, processes each frame, and detects human eyes in real time by leveraging pre-trained machine learning models.

The project demonstrates the fundamentals of computer vision, object detection, and image processing using Python.

---

## 🎯 Objective

To detect and locate human eyes in real-time video streams using OpenCV's Haar Cascade Classifier and visualize the detected eye regions with bounding boxes.

---

## 🛠️ Technologies Used

- Python
- OpenCV
- Haar Cascade Classifier
- NumPy

---

## ✨ Key Features

- Real-time eye detection using webcam feed
- Fast and lightweight implementation
- Eye region localization with bounding boxes
- Grayscale image processing for improved detection
- Easy-to-understand computer vision project

---

## 🔄 Working Process

1. Capture live video from the webcam.
2. Read frames continuously.
3. Convert frames to grayscale.
4. Apply Haar Cascade Classifier for eye detection.
5. Detect eye regions within the frame.
6. Draw bounding boxes around detected eyes.
7. Display the processed video in real time.
